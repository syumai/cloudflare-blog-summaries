理解度テスト: Agents Week 2026で行った発表内容の全て

全9問。基本問題（各曜日のテーマ・主要発表の対応関係）から応用問題（コンセプトの理解）の順に出題します。すべて回答したら「採点する」ボタンを押してください。

Q1. Agents Week 2026 が開催された期間はどれですか。

正解: B Agents Week 2026 は2026年8月3日（月）〜8月7日（金）の5日間開催され、その振り返り記事が8月13日に公開されました。記事冒頭のイントロで期間が示されています。

Q2. 月曜日（8月3日）のテーマとして正しいものはどれですか。

正解: A 月曜日のテーマは「実行環境とインフラ」です。@cloudflare/computer、Workers RPC の Python 対応、Kimi/GLM の大規模実行、Billable Usage API、TCP・gRPC 対応が発表されました。ADLC は火曜、Zero Trust は水曜、エージェント型インターネットは木曜のテーマです。

Q3. 「Cloudflare Wallets」が発表されたのは何曜日ですか。

正解: C Cloudflare Wallets は火曜日（エージェント開発ライフサイクルの日）に、Cloudflare Agents・ローカルトレース・CI/CD などと共に発表されました。エージェントが「エージェント経済」の参加者として安全に取引を行うための機能です。

Q4. 次のうち、水曜日（Zero Trust とセキュリティ）に発表されたものはどれですか。

正解: D WriteGuard は水曜日に発表された、MCPサーバー経由のリスクの高い書き込み呼び出しをきめ細かく制御する機能です。WebMCP と AI Search は木曜、Radar Researcher は金曜、Billable Usage API は月曜の発表です。

Q5. 記事全体を通じて Cloudflare が主張している、「エージェント経済」の課題として 正しくないもの はどれですか。

正解: B 記事の「背景・課題」では、課題は「モデル自体にとどまらず、アイデンティティ、通信、オーケストレーション、メモリ、オブザーバビリティ、セキュリティにまで広がっている」と述べられています。単純な GPU 演算性能の不足だけが課題だとは主張していません。

Q6. 火曜日に提唱された ADLC（Agent Development Lifecycle）の説明として最も適切なものはどれですか。

正解: A ADLC は、通常のソフトウェア開発における SDLC（Software Development Lifecycle）に代わる概念として提示されたもので、Cloudflare Agents のトレース・再実行・承認機能や、ローカルトレースによるデバッグ、CI/CD での自律修復など、火曜日の複数の発表がこの概念を具体化しています。SDLC との違いは、エージェント固有の検証・承認・トレースの仕組みが組み込まれている点です。

Q7. Agent Access Model（水曜日発表）の主な目的として最も適切なものはどれですか。

正解: C Agent Access Model は、エージェントが人間やサービスの代理として動作する際に、安全にリソースやサービスへアクセスできるようにするためのアクセス制御フレームワークです。同じ水曜日の ID 情報ベースの分析や WriteGuard と合わせて、「エージェントに何をどこまで許可するか」を細かく制御する Zero Trust 拡張の一環です。D の選択肢は木曜日発表の AEO の説明です。

Q8. 木曜日に発表された AEO（Answer Engine Optimization）とは何ですか。

正解: D AEO は「ランク付けから推奨へ」という発表タイトルが示す通り、従来の SEO（検索結果でのランク付け最適化）から、AI エージェント時代に「推奨される」ための最適化へと考え方を転換したものです。WebMCP や MCPv2 と並んで、木曜日の「エージェント型インターネット」のテーマを構成する発表の一つです。

Q9. 金曜日の発表「良い振る舞い・悪い振る舞いの見極め」が示す、bot 対策に関する考え方の転換として最も適切なものはどれですか。

正解: B 金曜日の発表は、従来の一律的な bot 対策の考え方を、エージェントの振る舞いを継続的に観察・評価する「continuous trust evaluation」へと転換するものです。エージェント型インターネットが普及する中で、単純なブロック／許可ではなく、振る舞いに基づいた柔軟な信頼評価が必要になるという問題意識に基づいています。
